# Security Policy

## Reporting a vulnerability

Report suspected security issues in the Ascend CLI to **security@straiker.ai**.
Include the affected version or commit, a description of the issue, and steps to
reproduce it.

Do not open a public GitHub issue for a security report, and do not disclose the
issue publicly until it has been resolved.

## What to expect

- Acknowledgement of the report within three business days.
- An assessment and, where a fix is warranted, a remediation timeline.
- Credit in the release notes on request.

## Scope

This repository contains the Ascend CLI, which connects to the Straiker Ascend
platform using customer credentials. Reports about the CLI, its adapters, and its
handling of credentials and target traffic are in scope. Issues in the Straiker
platform itself should also be sent to security@straiker.ai.

## Supported versions

The latest tagged release on the default branch is supported. Fixes are applied to
the latest version.
