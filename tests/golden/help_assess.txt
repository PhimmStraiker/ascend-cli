positional arguments:
  {run,diff,results,watch,status,pause,resume,list}
    run                 create->pause->resume->poll an assessment

    results             assessment findings summary
    watch               live view of a running assessment until it finishes
    status              ==SUPPRESS==
    pause               pause a running assessment (in-flight probes drain, see docs)
    resume              resume a paused assessment
    list                list assessments for an app (running assessments marked *)

  -h, --help            show this help message and exit
